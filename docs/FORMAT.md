# Формат вопросов (кратко)

Полная инструкция с примером и правилами YAML для чата-автора: [PROMPT_FOR_QUESTION_CHAT.md](PROMPT_FOR_QUESTION_CHAT.md).
Источник правды по схеме — `app/schema.py` (pydantic); неизвестные поля запрещены.

| type | нужно, кроме `id`, `topic`, `question` |
|---|---|
| `mcq` | `options` 2–8, ровно один `correct: true` |
| `multi` | `options` 3–8, верных от 1 до n−1 |
| `card` | `answer` |
| `open` | `answer` и `rubric` (2–10 пунктов) |
| `code` | `solution`; опционально `starter`, `tests`, `language` (по умолчанию python) |
| `match` | `pairs` 3–8 пар `{left, right}` (все `right` уникальны), опционально `extra_right` до 4 лишних вариантов |
| `order` | `items` 3–8 элементов в ВЕРНОМ порядке (перемешиваются при показе) |

Необязательные: `difficulty` (1–3), `tags`, `explanation`.

Файл — YAML-список вопросов (или объект с ключом `questions:`). Имена файлов и папок на `_` и `.` игнорируются.
Ответ LLM в обёртке ` ```yaml ` принимается как есть.

Что проверяет импорт: формат id/topic, правильность числа верных вариантов, лишние поля, синтаксис YAML
и опасные `\theta`/`\frac` в двойных кавычках (YAML молча превращает их в управляющие символы).
