# ML Тренажёр

Локальный тренажёр для подготовки к собеседованиям: тесты, карточки, кейсы, сопоставления, последовательности
и задачи на код. Повторения планирует FSRS, формулы рисует KaTeX, открытые ответы можно диктовать голосом
и получать оценку от модели.

## Запуск

Двойной клик по `run.bat` (первый раз сам поставит зависимости) или:

```bash
.venv\Scripts\python -m uvicorn app.main:app --port 8000
```

Открыть <http://127.0.0.1:8000>. **После обновления кода сервер нужно перезапустить.**

Тесты: `.venv\Scripts\python -m pytest -q`

## Типы вопросов

| Тип | Что делает отвечающий | Оценка |
|---|---|---|
| `mcq`, `multi` | выбирает варианты | автоматически |
| `match` | подбирает пару к каждому пункту (выпадающие списки) | доля верных пар |
| `order` | расставляет элементы стрелками ↑ ↓ | доля пар в верном взаимном порядке |
| `card`, `open` | отвечает голосом или текстом, затем проверка моделью или самооценка по рубрике | доля пунктов → оценка |
| `code` | пишет код, сверяет с эталоном вручную | самооценка |

## Оценка открытых ответов

Доля названных пунктов превращается в оценку: меньше 35% — «Не вспомнил», 35–59% — «Трудно», от 60% — «Хорошо».
«Легко» всегда выбирается вручную. Пороги лежат в `app/config.py` (`RATING_HARD_FROM`, `RATING_GOOD_FROM`).
Под каждой кнопкой видно, через сколько дней вопрос вернётся, а в статистику идёт реальная доля, а не округлённая оценка.

## Голос и проверка моделью (OpenRouter)

1. Создай ключ на <https://openrouter.ai/settings/keys> (лучше с лимитом по сумме) и пополни баланс на несколько долларов.
2. Скопируй `.env.example` в `.env` и впиши ключ: `OPENROUTER_API_KEY=...`. Файл `.env` не попадает в репозиторий.
3. Перезапусти приложение, открой **Настройки → Проверка ответов моделью → Проверить подключение**.

Как это работает: запись голоса (WAV прямо в браузере) → распознавание (по умолчанию `elevenlabs/scribe-v2`,
ему передаются только термины из базы, эталона он не видит) → текст можно поправить → проверка по эталону
(по умолчанию `anthropic/claude-haiku-5.5`) → разбор по пунктам и предложенная оценка. Окончательную оценку
выбираешь ты. Без ключа или при ошибке остаётся ручной режим с рубрикой.

Модели и месячный лимит расходов меняются в **Настройках**. Ориентир по цене: около $2–3 в месяц при 50 ответах
в день по минуте. Расходы считаются по данным OpenRouter (таблица `api_calls`).

Микрофон работает на `localhost` и по HTTPS (при удалённом доступе без HTTPS браузер его не даст).

## Режимы повторений

В **Настройках** выбирается режим: Интенсив (вероятность вспомнить 0,95, потолок 3 дня), Обычный (0,93, 14 дней),
Поддержка (0,90, 30 дней) или свои значения. Чем выше вероятность, тем чаще повторы; потолок ограничивает
максимальный интервал. Режим действует на следующие ответы, уже назначенные сроки не пересчитываются.

Рост интервала за один ответ дополнительно ограничен (`GROWTH_LIMIT` в `app/config.py`): «Трудно» — вспомнил, но очень слабо, поэтому не больше ×1,2 (минимум +1 день), «Хорошо» — не больше ×2,5, «Легко» — не больше ×3,5, «Не вспомнил» — завтра. Без этого FSRS после паузы отправлял к потолку даже ответ «Трудно»: он читает «вспомнил после долгого перерыва» как «запомнил надёжно». Прочность карточки подгоняется под фактический интервал, так что «Трудно» её не повышает.

## Как пополнять вопросами

1. Возьми промпт из [docs/PROMPT_FOR_QUESTION_CHAT.md](docs/PROMPT_FOR_QUESTION_CHAT.md) и вставь его в чат-автор.
2. Проси батчи («15 вопросов по собственным векторам»).
3. Вставь ответ на странице **Импорт**. Корректные вопросы сохранятся в `questions/inbox/`, ошибки покажутся списком, его можно скопировать обратно в чат.

Либо клади `.yaml`-файлы в `questions/` сам (любая вложенность) и жми «Пересканировать».
Файлы — источник правды; правка вопроса с тем же `id` прогресс не сбрасывает.
Демо-вопросы лежат в `questions/demo/`, удали папку, когда появятся свои.

## Как это устроено

| Что | Где |
|---|---|
| Формат вопросов и валидация | `app/schema.py` |
| Импорт YAML → SQLite | `app/importer.py` |
| Расписание повторений (FSRS), режимы | `app/srs.py`, `app/settings.py` |
| Сборка очередей (ежедневная, тема, слабые места, мини-собес) | `app/planner.py` |
| Распознавание речи и проверка ответов | `app/llm.py` |
| Веб-слой | `app/main.py`, `app/templates/`, `app/static/` |
| Прогресс, настройки, журнал расходов | `data/trainer.db` (SQLite; для бэкапа копируй файл) |

Переменные окружения (или строки в `.env`): `TRAINER_NEW_PER_DAY` (новых вопросов в день, по умолчанию 15),
`TRAINER_DATA`, `TRAINER_QUESTIONS`, `OPENROUTER_API_KEY`, `TRAINER_STT_MODEL`, `TRAINER_GRADER_MODEL`,
`TRAINER_LLM_MONTHLY_LIMIT`, `TRAINER_STT_LANGUAGE`.

## Доступ с телефона

- Быстро: поставить Tailscale на ПК и телефон, запустить сервер с `--host 0.0.0.0` и открыть `http://<имя-пк>:8000`.
  ПК должен быть включён. Для микрофона нужен HTTPS (`tailscale serve`).
- Постоянно: Docker/VPS с томом под `data/` и `questions/`, ключ OpenRouter в секретах хостинга. Авторизации в
  приложении нет: перед публикацией нужно закрыть его паролем или VPN, репозиторий держать приватным.
